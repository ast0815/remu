# AGENTS.md — ReMU

ReMU (Response Matrix Utilities) is a scientific Python library for binned
likelihood calculations and hypothesis testing with response matrices.
Supports Python 3.11–3.15 (CI matrix).

## Setup

- `.venv/` is gitignored and may not exist. Run `. setup.sh` to create/activate
  it and install everything (`uv sync --all-extras`). Requires `uv`. Do all
  development inside `.venv`.
- An installed package matters: `src/remu/_version.py` is generated by
  hatch-vcs, so `remu.__version__` is `None` in an uninstalled checkout.
- Dependencies live in `pyproject.toml`: runtime under
  `[project].dependencies`, optional sets as extras (`mcmc`, `test`, `docs`,
  `examples`), dev tools under `[dependency-groups].dev`. The
  `*-requirements.txt` files are compatibility shims for pip-based tooling
  (CI, Read the Docs) and must keep working.
- `uv.lock` pins the resolved environment: run `uv lock` after changing
  dependencies in `pyproject.toml` and `uv lock --check` to verify it is
  up to date.

## Commands

- All tests: `nox -s tests` (runs only installed Python versions).
- One Python version: `nox -s tests-3.12`.
- Single test: `nox -s tests -- -k test_name`, or without nox
  `./run_tests.sh -k test_name` (coverage + unittest, forwards args).
  `.venv/bin/python -m pytest tests.py -k test_name` also works.
- Lint/typecheck gate: `nox -s lint` → flake8, `black --check`,
  `isort --profile black --check`, `mypy src/` (all on `src/` and `tests.py`).
- Format: `black src/ tests.py` and `isort --profile black src/ tests.py`.
- Docs: install the docs extra (`uv sync --extra docs`), then
  `cd docs && make html` (Sphinx + numpydoc, sources are `.rst`).
- Examples: `nox -s examples` or `./run_examples.sh`. Expensive and
  order-dependent: each `docs/examples/<NN>/do_everything.sh` consumes outputs
  of earlier examples (e.g. `03` reads `../00/modelA_data.txt`). Run only when
  strictly necessary.
- Pre-commit is required before committing: `pre-commit run --all-files`.

## Architecture

- `src/remu/binning.py` — `PhaseSpace` and the `Binning` hierarchy
  (`RectangularBinning`, `CartesianProductBinning`, `LinearBinning`,
  `RectilinearBinning`). All binning classes are YAML-(de)serializable via
  `remu.yaml`.
- `src/remu/migration.py` — `ResponseMatrix` and migration-matrix operations.
- `src/remu/likelihood.py` — `DataModel`/`PoissonData`, the `Predictor`
  hierarchy (`TemplatePredictor`, `MatrixPredictor`, `ComposedPredictor`, …),
  `LikelihoodCalculator`, `HypothesisTester`.
- `src/remu/matrix_utils.py`, `plotting.py` (`get_plotter` dispatch by binning
  type), `likelihood_utils.py` (emcee helpers, imports `emcee` lazily),
  `yaml.py` (NumPy 2 scalar representers).
- Tests are one monolithic `tests.py` of `unittest` classes, executed with
  pytest in nox. Fixtures live in `testdata/`.
- Parallelism is opt-in by monkeypatching the module-level `mapper = map` in
  `binning.py` / `likelihood.py` (e.g. `likelihood.mapper = pool.map`; see
  `docs/examples/02`). Do not add a hard dependency on multiprocessing.

## Gotchas

- `.pre-commit-config.yaml`'s mypy hook still has `files: histoprint` (stale
  copy from another project), so pre-commit does **not** typecheck this repo.
  Run `mypy src/` explicitly.
- Running `tests.py` as `__main__` sets `np.seterr(all="raise")`: numeric
  warnings become errors. Nox also runs pytest with custom DeprecationWarning
  filters.
- flake8 config ignores `E203,E402,E501,W503`; pre-commit adds
  `flake8-bugbear` and `flake8-print` (so stray `print` is an error outside
  `docs/`).
- Example data/plots under `docs/examples/` are tracked in git; running the
  examples rewrites them, producing noisy diffs.
- The examples directory is `docs/examples/`, not `docs/example/`.
